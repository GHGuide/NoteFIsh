# Pages in the companion design

Each file here draws one sheet of the NoteFish workspace in the companion design
(the boards in `design/*.dc.html`, generated by `design/build.py` and
`design/moments.py`, which are the source of truth for layout, copy and rhythm).
`web/App.jsx` owns state and the sidebar and renders `<Page {...common} />`
inside the sheet; `web/shell.jsx` has the building blocks; `web/design.css` the
classes (all prefixed `ds-`); `web/lib.jsx` the shared logic lifted from the old
app (recorder hook, voice dialogs, registers, reading scripts, helpers).

## The sheet's rhythm

A page returns a fragment in this order (skip what the board skips):

```jsx
<Toolbar back={…} onBack={…}>{/* right-side tools, e.g. a Focus button */}</Toolbar>
<Title title="Calls" sub="This week · 23 calls · 1 h 52 min translated" />
<Tabs items={[{ key: 'all', label: 'All' }, …]} value={tab} onChange={setTab} />
<ReadBar right={…}>…</ReadBar>            {/* optional: a search field, a label, a "+ Add" input */}
<Body>…</Body>                            {/* scrolls; flex: 1 */}
<Ask placeholder="Ask about your calls" scope="calls" />   {/* sits at the bottom */}
```

Everything inside the sheet is a `.ds-col` (640px column, centred). `Body` is a
column that scrolls. For custom blocks between the tabs and the body use
`<Col className="…" style={{ marginTop: 18 }}>`. Lists are `Row`s; settings are
`Setting`s; radio-style choices are `Option`s; small numbers are `Stat`s in a
`.ds-stats` grid; language shares are `Bar`s.

## Building blocks (web/shell.jsx)

`Puff`, `LogoMark`, `Avatar` (`who` = agent object, name string or 'workspace'), `avatarOf`,
`PUFFS`, `SWATCHES`, `Toolbar`, `Title`, `Tabs`, `ReadBar`, `Body`, `Col`, `Label`,
`Dot`, `Status`, `Chip`, `Stat`, `Bar`, `Row`, `Btn` (kind ink|green|ghost|red, small, pill, grow),
`TextBtn`, `Pill` (on), `SelectPill`, `Field`, `Switch`, `Option`, `Setting`, `Wave`,
`Typing`, `Empty`, `Spinner`, `Ask`, `Sheet` (a small modal). Read the file for props.
Icons come from `lucide-react` (already a dependency), 13–16px, stroke 1.65–1.7.

## `common` (the props every page gets)

- `data`: `{ voices, settings, calls, setup, agents, floor, agentId, session }`
- `navigate(path)`, `route`: `{ path, params: { id? }, query: { tab? … }, full }`
- `loading`, `error`, `setError(msg)`, `setNotice(msg)` (toast)
- `saveSettings(patch) → bool`, `saveOwned(patch) → bool` (writes to the seat when there is one, else the workspace), `owned(key)` (reads the same way: `owned('phrases')`, `owned('layout')`, `owned('avatar')`, `owned('formality')`, `owned('registers')`, `owned('persona')`)
- `refreshVoices(savedVoice?)`, `updateCall(call)`, `refreshFloor()`, `reload()`
- `sharedDemo`, `trainingNotes` (`{ [voiceId]: note }`), `multiAgent`, `hasFloor`, `roster` (active agents), `seat` (the agent this desk answers as, or null), `seatActions` `{ take(id), leave(), pause(reason), resume() }`
- `partialCaption`: `{ callId, text, shown }` or null — what the caller is saying right now
- `connection`: 'connecting' | 'connected' | 'reconnecting'
- `invitation`, `setInvitation` (a caller link: `{ url, expiresAt }`)
- `audioReady`, `enableAudio()`, `clearAudio()`, `setAudioMuted(bool)`
- `focus`, `setFocus(bool)` (hide the sidebar), `openFree()`

## Data shapes

- call: `{ id, from, to, transport: 'browser'|'twilio', state: 'ringing'|'in_call'|'ended', phase: 'listening'|'translating'|'synthesizing'|'playing'|…, stage, mediaConnected, startedAt, answeredAt, endedAt, agentId, voiceId, agentLanguage, customerLanguage, detectedLanguage, callerTone, error, transcript: [{ id, t, speaker: 'agent'|'customer', sourceLang, targetLang, textSource, textShown, delivery: 'played'|'pending'|'caption'|…, feeling, why, tag }], ticket: { issue, address, dispatch: 'none'|'requested'|'confirmed'|true|false, dispatchConfirmedAt } }`.
  For an agent line, `textSource` is what the agent said (their language) and `textShown` the translation the caller heard. For a caller line, `textSource` is the caller's words and `textShown` the agent's-language caption.
- settings: `{ voiceId, agentLanguage, customerLanguage ('auto' allowed), queueName, registers: { calm: voiceId… }, layout, phrases: [{ id, text }], persona, glossary: [{ id, term, kind: 'keep'|'as'|'spell', as }], formality: 'formal'|'casual'|'match'|null, avatar: { variant, color, face } }`
- agent: `{ id, name, voiceId, agentLanguage, customerLanguage, registers, layout, phrases, persona, formality, avatar, archived }`
- floor: `{ waiting: [{ id, from, transport, startedAt, position }], agents: [{ id, name, state: 'available'|'on_call'|'paused'|'offline', paused, pauseReason }] }`
- voice: `{ id, name, description, language, kind: 'enrolled'|'licensed', status: 'training'|'ready'|'failed', archived, register, referenceId }`
- setup (`/api/status`): `{ ready, blockers, providers: { fish: { configured }, openai, twilio }, audioAvailable, publicUrl, phoneNumber, webhookUrl, integrations: { webhook: { configured, url }, zendesk: { configured }, exportApi: { configured } }, access: { mode }, floor: { multiAgent, maxAgents, reason } }`
- languages: `import { languages, languageName } from '../lib.jsx'` (`languages` = `[{ code, name }]`).

## Rules

- Edit only your own page file(s) under `web/pages/`. If a page needs styles the
  design system lacks, put them in `web/pages/<page>.css` with classes prefixed
  `<page>-` and import it from the page. Do not edit `shell.jsx`, `design.css`,
  `App.jsx`, `lib.jsx` or the server; report what you would need instead.
- The project uses the classic JSX transform: every JSX file starts with `import React …`.
- Reuse the logic in the old app (`/private/tmp/claude-501/-Users-leonardo-Downloads-NoteFIsh/52985d21-5d4a-4c92-aef3-d09a724e7d30/scratchpad/App.old.jsx`, read-only): the recorder, seats, invitations, PTT keys, ticket saving. Keep behaviour; change only the clothes.
- Match the board: same words, same order, same weights. Real data replaces the sample data; empty states get the board's "The conversation appears here." tone.
- Check your work: `npx vite build` (from the repo root), then
  `node /private/tmp/claude-501/-Users-leonardo-Downloads-NoteFIsh/52985d21-5d4a-4c92-aef3-d09a724e7d30/scratchpad/shots/shoot-page.mjs /calls /private/tmp/claude-501/-Users-leonardo-Downloads-NoteFIsh/52985d21-5d4a-4c92-aef3-d09a724e7d30/scratchpad/shots/<name>.png`
  (the server on 127.0.0.1:3001 serves `dist/`; the script prints page errors) and look at the PNG with the Read tool.
  Other people build at the same time; if a screenshot comes back broken, rebuild and shoot again.
- The board for a page: `design/<Board>.dc.html` rendered, or the Python that made it in `design/build.py` / `design/moments.py`.
