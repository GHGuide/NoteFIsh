# Landing page

`index.html` is the standalone marketing page (open it directly, or serve the folder). `notefish-landing.html` is the same page as an artifact fragment (no html/head/body) used to publish the Claude artifact. Structure and rhythm follow wisprflow.ai (floating nav, serif hero with an italic half, crossing ribbons, rounded colour bands, tabs, FAQ); every visual element is NoteFIsh’s own. Vendor and stack names are deliberately absent from the page; `research/wispr-flow-teardown.md` holds the measured reference.
